# static-page

Landing institucional da marca Limitless: recursos do app, estética alinhada ao tema do produto (paleta escura, acentos verde e dourado), efeito parallax em camadas na rolagem e tipografia Cormorant Garamond + Inter. Página estática em HTML único (sem build).

**Como abrir:** abra o arquivo `index.html` no navegador (duplo clique ou `open index.html` no terminal).
